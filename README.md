# Translation App

A translation application developed for CodeAlpha’s Artificial Intelligence internship.

## Features

- Select source and target languages
- Translate typed text
- Swap languages and copy translations
- View recent translation history
- Voice input and speech playback in supported browsers

## Technologies

Python, HTML, CSS, JavaScript, and the MyMemory translation API.

## How to run

## Notes

Translation requires an internet connection. Voice features depend on browser support, microphone permissions, and available speech voices. Translation accuracy can vary.
